Tool memory · what it learned about the source

- Read GitHub meta.cc as notification-context metadata: author@noreply.github.com indicates authorship of the issue or PR, not repository maintainership or authority to assign contributors; ci_activity@noreply.github.com identifies workflow notifications. For workflow mail, extract the repository and workflow name from the subject instead of classifying from 'Run failed' alone.
- For hackathon submission confirmations, read the snippet's salutation and submission description before classifying from the subject. 'Submission Successful for UniHack' alone does not distinguish a prototype receipt addressed to Nilesh from a team receipt addressed to Sanskaar Undale.
- For Hack2skill messages, identify the requested step separately from the advertised benefits: 'Cohort ... filling fast' and 'complete your registration' identify a cohort-registration reminder, even when the snippet advertises live workshops with Google Cloud experts. Do not classify it as a workshop invitation merely because workshops are mentioned.

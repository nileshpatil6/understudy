# Judgment memory

Rules the agent has learned about how this user handles items. One rule per line, prefixed with `- `.

- Generic marketing, discount offers, win-back campaigns, and social-network engagement or recommendation notices without a direct personal request: ignore
- One-time login-code emails, even when the surrounding login session is not visible: archive
- Routine invoice-ready, receipt, or charge-confirmation emails that do not explicitly require payment or flag a billing problem: archive
- Third-party software or repository release announcements without a requested task on the user's own work, regardless of version significance: archive

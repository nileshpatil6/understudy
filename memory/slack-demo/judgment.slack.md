# Judgment memory

Rules the agent has learned about how this user handles items. One rule per line, prefixed with `- `.

- An urgent production alert reporting sustained service degradation with no acknowledged owner requires incident response rather than just a Slack acknowledgment — act
- A direct request from a person for the user's review or feedback on a plan or document, especially before a deadline, calls for a response to the requester — reply
- An informational broadcast announcing a completed business milestone, with no outstanding request or follow-up, should be cleared rather than left untouched — archive
- An automated reminder explicitly stating that the user's required contribution is still missing remains actionable; a stated closing time alone does not establish that the task is obsolete — act
- A broadly shared draft, newsletter, or resource offered for optional reading, with no personal request or required contribution from the user — ignore
- Casual social notices, jokes, GIFs, and entertainment posts with no substantive request to the user, whether posted by people or apps — ignore
- A direct human request for operational help or incident triage, such as asking the user to check a pager alert before escalation, calls for a response to the requester — reply
